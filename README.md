# telcoin-builder-wao
Independent Telcoin builder companion powered by the Wise Autonomous Organization (WAO) framework: cited knowledge, project workspaces, human-guided AI collaboration, and approval-gated developer tools. Not affiliated with Telcoin.

## Local functional MVP

The existing brief generator and browser team board are preserved. Open `/workspace` for authenticated, persistent project and collaboration workflows. Agent execution and MCP adapters are clearly labeled local mocks. Financial operations and deployment are disabled.

Run with Node 22 from the parent workspace using `npm run local:setup`, `npm run local:build`, and `npm run local:start`. The shared workflow engine is in `../packages/wao-core`; it must accompany this project. See `../LOCAL_MVP.md` for architecture, access, test commands and limitations.
